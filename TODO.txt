healsparse
----------
build up a footprint as we go.  Then and it with the
star mask and the tract box.

        footprint = healsparse.HealSparseMap.make_empty(32, 2**17, bool, bit_packed=True)

        for cell_i in range(1, 21):
            for cell_j in range(1, 21):
                if cell_worked:
                    # a cell is a polygon of great circles on the sphere since
                    # the WCS uses a gnomonic projection.
                    # first get pixel bounds as vertices array
                    ci = patch_info.getCellInfo((cell_i, cell_j))
                    bb = ci.getInnerBBox()
                    data = np.array([
                        [bb.beginX, bb.beginY],
                        [bb.endX, bb.beginY],
                        [bb.endX, bb.endY],
                        [bb.beginX, bb.endY],
                    ], dtype=np.float64)
                    # then convert to ra,dec on sky
                    ra, dec = wcs.pixelToSkyArray(data[:, 0], data[:, 1], degrees=True)
                    # finally use a spherical polygon
                    footprint |= healsparse.Polygon(ra=ra, dec=dec, value=True)

        ip = tract_info.inner_sky_region
        ramin = ip.getLon().getA().asDegrees()
        ramax = ip.getLon().getB().asDegrees()
        decmin = ip.getLat().getA().asDegrees()
        decmax = ip.getLat().getB().asDegrees()
        footprint &= healsparse.Box(
            ra1=ramin,
            ra2=ramax,
            dec1=decmin,
            dec2=decmax,

globular cluster mask (noted 2026-09-23)
----------------------------------------
A post-processing footprint cut around the Galactic globular
clusters, like the star-proximity exclusion: a circle per cluster
from a cluster catalog (Harris 1996/2010 or Baumgardt), radius tied
to the half-light or tidal radius.  Not done in run-dp2-v01.1.
Seen so far: M30 (05891-00042: 4085 census stars, 39 percent of the
patch masked, the slowest mop-up patch), M75 (06103-00023/24),
NGC 7492 (07059-00058); M55 (04779-00025) and M72 (07509-00052)
were skipped patches in v00.  First step: match a cluster catalog
against run-dp2-v01.1-footprint.hsp to find them all; the shear
density map (stats/, nside 2048) should show them as spikes.  The
HyperLEDA galaxy mask does not cover clusters.
